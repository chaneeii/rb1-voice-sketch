# RB1 Voice Sketching

Participant page for the RB1 project (DM2350 Human Perception for Information Technology, KTH).

Flow: participant code → consent → short questionnaire → voice recordings (warm-up and two robot turn clips) → export as `RB1_<code>_<date>.zip`.

- Static site, no server. Deploy the repository root on Vercel.
- Recording needs HTTPS (Vercel provides it).
- Progress is saved in the participant's browser, so an interrupted session can be resumed on the same phone.
